## Getting Started

Clone the repository:

```bash
git clone https://github.com/wissemHANACHI/taskify-dashboard.git
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
